# Guía rápida de Markdown

## Títulos
```
# Título principal
## Subtítulo
### Sub-subtítulo
```

## Texto
```
**negrita**
*cursiva*
```

## Listas
```
- Elemento 1
- Elemento 2
```

## Listas numeradas
```
1. Primer paso
2. Segundo paso
```

## Bloques de código
Para comandos o código, usa 3 comillas invertidas:
\`\`\`
pip install pandas
\`\`\`

## Tabla simple
```
| Columna 1 | Columna 2 |
|-----------|-----------|
| Dato 1    | Dato 2    |
```

Ejemplo aplicado — tabla de resultados:
```
| Categoría   | Total ventas |
|-------------|--------------|
| Electrónica | $3,361,610   |
| Ropa        | $2,687,020   |
```
